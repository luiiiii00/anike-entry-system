# Trade Validator

Quiero que construyas una aplicación web profesional llamada:

ANIKE EJEPIKA  TRADING ENTRY SYSTEM

Es una herramienta de evaluación de operaciones de trading antes de entrar al mercado. NO debe prometer ganancias, predecir el mercado ni presentarse como asesor financiero. Su objetivo es ayudar al trader a seguir un proceso estructurado, controlar el riesgo, evitar entradas impulsivas y registrar sus operaciones.

La aplicación debe sentirse como un producto SaaS premium, moderno y profesional, no como un formulario genérico.

15. HARD NO-TRADE RULES

Estas reglas deben tener prioridad sobre el score.

Si alguna se cumple, la operación queda automáticamente marcada como:

NO TRADE

Reglas:

No existe un punto claro de invalidación.

El riesgo supera el límite establecido.

No existe espacio suficiente hacia el objetivo.

La entrada depende exclusivamente de intuición.

La operación está motivada por FOMO.

La operación busca recuperar una pérdida.

Se está entrando antes de la confirmación definida.

El setup no pertenece al plan operativo.

Mostrar una alerta:

“Tu score puede ser alto, pero una regla crítica fue incumplida. La operación queda bloqueada.”
